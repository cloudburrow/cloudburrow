# API coverage

Generated by `go run ./tools/coverage` from the Go proto descriptors, a checked-in registry
(`tools/coverage/registry.json`) and `// covers:` annotations on `test/compat` tests. CI runs
`go run ./tools/coverage -check` and fails when this is stale or an annotation is wrong, and
`tools/coverage/servers_test.go` proves every Unimplemented method returns `codes.Unimplemented`.
Where a method stays Unimplemented, or Implemented with no official-SDK test that can reach it,
`tools/coverage/reasons.json` says why, and its row shows the reason.
Do not edit these files by hand.

**Statuses.** *Verified*: an official-SDK compat test, linked, exercises it. *Refused*: a compat
test proves the upstream emulator refuses it. *Unimplemented*: CloudBurrow returns `UNIMPLEMENTED`, proven
in-process. *Implemented*: served, with no official-SDK test yet. *Not served*: not registered on any port.
*Unknown*: an upstream-backed method no test covers, so nothing is claimed. *Unverified codes*: error codes a
test asserts that Google does not document (`// unverified:`), listed on each service's page.
