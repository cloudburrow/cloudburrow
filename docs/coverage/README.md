test proves the upstream emulator refuses it. *Unimplemented*: CloudBurrow returns `UNIMPLEMENTED`, proven
in-process. *Implemented*: served, with no official-SDK test yet. *Not served*: not registered on any port.
*Unknown*: an upstream-backed method no test covers, so nothing is claimed. *Unverified codes*: error codes a
test asserts that Google does not document (`// unverified:`), listed on each service's page.
